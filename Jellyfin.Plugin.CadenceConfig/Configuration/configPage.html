Deezer playlist sync

Importing a Deezer playlist (via the Cadence client) creates a matching Jellyfin playlist and subscribes it. The "Sync Deezer Playlists" scheduled task then keeps each playlist up to date, adding tracks as they arrive in your library (e.g. after Lidarr fills in a previously-missing artist). It only adds — it never removes tracks.

How often the sync task runs. Default 12. Takes effect after the next Jellyfin restart.

Storyteller (Whispersync + read-along)

Set up once, here. With a Storyteller URL and a Storyteller admin login saved, every Jellyfin user gets read-along text and a shared listening/reading position in Cadence with no setup on their side: users with no account below get one created automatically the first time they open a book in Cadence; map a user to an existing Storyteller account if they already have one. Tokens and generated passwords stay on this server.
